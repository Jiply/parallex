# Security policy

## Supported version

Security fixes target the latest commit on `main`. No older release line is
currently maintained.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting feature if it is enabled for the
repository. Otherwise, contact the repository owner privately through their
GitHub profile before sharing details.

Do not open a public issue containing:

- `auth.json` or Keychain data;
- access tokens or API keys;
- rollout files or transcript excerpts;
- account email addresses;
- full local paths or process environments; or
- screenshots that reveal private session or account data.

Include the affected commit, macOS version, Codex version, impact, and minimal
reproduction steps using synthetic data.
